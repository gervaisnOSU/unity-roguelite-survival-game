Unity Roguelite Survival Game: A Unity-based survival game developed during CS361 Software Engineering at Oregon State University.

Overview
The project was developed using a microservice-based architecture. The game client communicated with external Python microservices for various gameplay-related systems.

Features:
- Player movement
- Enemy encounters
- Combat systems
- Health systems
- Survival-based gameplay
- Score tracking
  
Technologies:
- Unity
- C#
- Python
- Git
- Microservice Architecture

Repository Structure: Assets/ Packages/ ProjectSettings/

Project Context: This project was completed as part of a team software engineering course and demonstrates integration of Unity gameplay systems with external services.
